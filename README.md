# API Mundial 2026


Este proyecto es el backend de un torneo ficticio "Mundial 2026". Permite consultar las selecciones que participan, filtrarlas por continente o por si han sido campeonas, ver sus copas ganadas, y registrar los resultados de las semifinales y la final del torneo.

No usa base de datos: todos los datos viven en memoria mientras el servidor está corriendo, así que si lo reinicias, los resultados que hayas registrado se pierden.

## Cómo levantar el proyecto

```bash
npm install
npm run dev
```

El servidor queda escuchando en **http://localhost:3000**.

## Colección de Postman

Está en `postman/Mundial2026deyvispostman_collection.json`. Impórtala en Postman para probar todas las rutas.
